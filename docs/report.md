## Подсказки к заполнению

- **User vs Traffic acquisition.** User acquisition считает пользователей по *первому* источнику (First user source), Traffic acquisition — сеансы по источнику *каждого* сеанса (Session source). Если человек пришёл из Instagram, а потом вернулся напрямую, в первом отчёте он один раз «instagram», во втором — один сеанс instagram и один (direct).
- **Открытая и закрытая воронка.** В закрытой (Closed) считаются только те, кто начал с первого шага `page_view`; в открытой (Open) — входящие на любом шаге. Поэтому в открытой на последних шагах чисел больше: например, посетитель из автоответа сразу попал на pdd-test.html и нажал кнопку заявки, минуя `view_category`.
- **Раздел «Реклама»** (пути к ключевым событиям) в России не заполняется — Google Реклама не подключается. Цепочку действий перед заявкой показывает обратный путь из 8.2.
- **Заявки в таблице и generate_lead.** Возможные причины расхождения: блокировщики рекламы и отказ от cookie (заявка дошла, события нет), уход со страницы до отправки события, повторная отправка (`request_id` уже есть — приёмник вернул ошибку, generate_lead не ушёл), тестовые заявки, отправленные напрямую в приёмник.
- **Атрибуция:** Admin → Attribution settings — модель (по умолчанию Data-driven) и окна (по умолчанию 30 дней для ключевых событий привлечения и 90 дней для остальных). Записать фактические значения ресурса.
