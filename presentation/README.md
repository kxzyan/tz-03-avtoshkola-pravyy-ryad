# Презентация проекта

14 слайдов о сайте автошколы «Правый ряд»: задача, страницы сайта, калькулятор и тренажёр, путь заявки, GA4 и DebugView, UTM-ссылки, Instagram и ManyChat, первые данные и следующие шаги.

| Файл | Что это |
|---|---|
| `presentation.pdf` | презентация для показа и печати |
| `slides/` | каждый слайд отдельной картинкой PNG 1920×1080 |
| `notes.md` | текст выступления к каждому слайду |
| `presentation.html` | исходник слайдов, открывается в браузере |
| `img/` | снимки экранов, использованные на слайдах |

Цвета и шрифты взяты с сайта: синий `#1F6FD1`, жёлтый `#F5C518`, графит `#1E2329`.
